# Changelog

Every GitHub release note starts with the entry for its tag, under "Changes" (`.github/workflows/release.yml`
runs `tools/changelog.mjs`). One entry per version, newest first, **at most 5 short bullets**: what a
user of the simulator notices, not the commit list (that one follows, generated by GitHub).

## 1.0.4

- Fault injection now answers with the error frame the real 2.7.2 sends (`(M?r)`), and the Trafego panel shows faults exactly as they went over the wire.
- New `reiniciar_processo` control that mimics the 2.7.2 process restart, for testing how a PDV recovers from a concentrator that comes back.
- Setting a profile (`set_perfil`) sorts ports numerically (COM2 before COM10).
