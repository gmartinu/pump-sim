# Changelog

Every GitHub release note starts with the entry for its tag, under "Changes" (`.github/workflows/release.yml`
runs `tools/changelog.mjs`). One entry per version, newest first, **at most 5 short bullets**: what a
user of the simulator notices, not the commit list (that one follows, generated by GitHub).

## 1.0.3

- First public release: a Companytec concentrator simulator (CBC01–CBC06, Horustech, Concept) over TCP, plus a `simulador-2.7.2` profile that answers like the real SimuladorCBC 2.7.2, quirks included, measured on a bench.
- Web UI in Portuguese: forecourt, basic commands, prices, configuration, traffic console with fault injection, Identfid.
- Windows single executable (`pump-sim-win-x64.exe`) that opens in its own frameless window, or in Edge/the browser without WebView2; also on npm (`npx pump-sim --ui`).
- AI agents: control API over HTTP + WebSocket and MCP over HTTP at `<control>/mcp` (or stdio, `pump-sim mcp`), with ready-to-copy configs for Claude Code, Claude Desktop, Cursor and VS Code.
- Traffic recording to JSONL, replay as concentrator or as client, and a differential runner against a real 2.7.2.
