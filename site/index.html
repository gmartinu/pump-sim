Simule o concentrador. Teste a pista sem ir ao posto.

pump-sim é um simulador open source dos concentradores Companytec (CBC, Horustech, Concept e Identfid), fiel ao SimuladorCBC 2.7.2, com API de controle, servidor MCP e console de tráfego para devs e agentes de IA.

Pronto para agentes

API HTTP de controle só em loopback e servidor MCP stdio com o mesmo catálogo de comandos. O relógio manual deixa o CI do seu cliente determinístico.

POST /api/comandos/<comando>

Cada leitura e escrita do socket, por porta e conexão. Injete uma falha e veja o seu software reagir.

Início rápido

Três comandos.

macOS, Linux ou Windows com Node 22+. No Windows, o .exe dispensa tudo isso: dois cliques e a interface abre.

1
Clonar
$git clone https://github.com/gmartinu/pump-sim && cd pump-sim
2
Instalar e compilar
$npm install && npm run build && npm link
3
Subir com a interface
$pump-sim --profile simulador-2.7.2 --ui

Para agentes

Seu agente dirige a pista.

pump-sim mcp expõe o catálogo de comandos como ferramentas MCP. Cada chamada vira um POST na API de controle: o agente abastece, apresenta cartão, injeta falha, avança o relógio e lê o estado.
